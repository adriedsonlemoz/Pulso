# Pulso Bateria 0.1.0-alpha.25

**Configurações redesenhadas, com categorias e interface mais consistente.**

- Menu inicial compacto, com status das opções e acesso por assunto: Aparência, Leituras, Monitoramento, Alertas, Estimativa, Diagnóstico, Backup e Sobre.
- Seletores em botões independentes, sem barras segmentadas gigantes; cabeçalhos, espaçamentos e ícones padronizados.

- Sem alterações nas medições, Labs, monitoramento, Room v7, backup JSON v5, AndroidManifest, identidade ou assinatura.
